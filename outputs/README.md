## 2. Publication Figures (`figures/`)

The pipeline produces high-resolution publication-quality figures:

* **`F2_kernel_comparison.png`**: High-resolution side-by-side heatmaps of Classical RBF, Classical Polynomial, and Quantum `ZZFeatureMap` kernel matrices alongside the elementwise difference matrix.
* **`F3_permutation_null.png`**: Empirical distribution of Centered Kernel Alignment under $B=100$ independent quantum feature permutations ($\mu_{\text{null}} = 0.1821 \pm 0.0074$) vs observed CKA ($0.2484$, $z=8.91, p < 0.01$).
* **`F4_jaccard_distribution.png`**: Multi-panel distribution of local neighborhood Jaccard overlap across $k \in \{5, 10, 15, 20\}$.
* **`F5_qi_landscape.png`**: Bi-dimensional scatter mapping observations across Quantum Unusualness ($QU$) vs Representation Disagreement ($RD$).
* **`F6_kernel_control_cka.png`**: Benchmarking quantum structural divergence against classical Linear, Polynomial (degree 3), and Random Fourier Feature (RFF) controls.
* **`F7_ablation.png` & `F7a_component_correlation.png`**: Component ablation rankings and pairwise correlation matrix between $QAS, CAS, N, B$.
* **`F8_cross_dataset.png`**: Comparative CKA and neighborhood overlap across UCI Red Wine, sklearn Wine, and Wisconsin Breast Cancer datasets.
* **`F9_robustness.png` & `F9b_kernel_concentration.png`**: Circuit depth ($r=1,2,3$), feature map ablation ($ZZ$ vs $Z$), and off-diagonal eigenvalue concentration diagnostics.
* **`F10_scalability.png`**: Empirical runtime scaling verifying $O(N^2)$ execution complexity.

## 3. Empirical Data Tables (`tables/`)

Key statistical results are exported as CSV files:

| File | Description |
| :--- | :--- |
| `cross_dataset_results.csv` | Cross-domain evaluation across UCI Red Wine, sklearn Wine, and Wisconsin Breast Cancer. |
| `permutation_control_upgraded.csv` | Full quantum permutation test results ($B=100$) including null mean, standard deviation, $z$-score, and empirical $p$-value. |
| `quantum_permutation_progress.csv` | Checkpoint log containing all 100 individual quantum permutation CKA evaluations. |
| `synthetic_validation.csv` | Precision@$k$ metrics across Gaussian, Two Moons, and Concentric Circles manifolds. |
| `shot_noise_robustness.csv` | Stability evaluation under finite measurement shot sampling (1024, 4096, 8192 shots). |
| `classical_kernel_control_cka.csv` | Kernel alignment and divergence ($D = 1 - \text{CKA}$) for classical controls. |
| `bootstrap_ci.csv` | 95% non-parametric bootstrap confidence intervals ($B=1000$) for primary metrics. |
| `qi_ablation.csv` & `qi_weight_sensitivity.csv` | Component ablation study and continuous $\lambda$ sensitivity sweep. |
| `top_q_interesting_v2.csv` | Ranked observations with decomposed $QAS, N, B, QU, RD,$ and $QI_{v2}$ scores. |

## 4. Precomputed Kernel Matrices (`kernels/`)

Binary NumPy arrays (`.npy`) containing pairwise similarity matrices:
* `K_classical.npy`: Baseline Gaussian RBF kernel ($150 \times 150$).
* `K_quantum.npy`: Primary `ZZFeatureMap` (depth 2) fidelity kernel ($150 \times 150$).
* `K_classical2.npy` & `K_quantum2.npy`: Secondary dataset kernel matrices.
